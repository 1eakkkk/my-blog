Markdown 语法指南

# 标题一级标题（## 二级，### 三级）
**加粗**加粗文字
*斜体*斜体文字
[文字](链接)插入链接
![替代](图片URL)插入图片（上传后自动生成）
`代码`行内代码
```代码块```多行代码块
> 引用引用文字
- 列表项无序列表（数字+点=有序）
| A  | B  |
| --- | --- |
| 1  | 2  |
GFM 表格（需含表头分隔行）

更新日志

只保留真正影响体验和维护的变更，近期更新展开，历史记录收起。

当前 v2.8.0
v2.8.0 (2026-10-12)

v2.8.0 — 留住记录，邀请朋友，找回对话。

  • 草稿按账号保存，刷新可恢复，显示保存状态，失败可重试或导出 Markdown。
  • 新账号需要邀请码；本站媒体通过登录鉴权读取，兼容已有文件。
  • 帖子和评论移入回收站，恢复后保留原时间、链接、评论和点赞。
  • 搜索显示关键词附近的正文与评论；日期、分类、排序和搜索保存在链接中。
  • 新增“回复我的”及未读标记，点击直接到达评论；回访首页更紧凑。
  • 新增完整数据库、媒体备份与独立恢复校验工具。
v2.7.1 (2026-10-11)

v2.7.1 — 评论讨论与回复分页、稳定楼层和定位。

  • 主评论按讨论分页，回复归属原讨论，修复跨页回复漏显示。
  • 长讨论支持加载更多回复，置顶不改变楼层编号。
  • 评论链接直接定位到对应回复页，发表后可立即看到自己的新评论。
  • 连续点击不重复加载，失败支持重试，快速切换帖子不会混入旧评论。
v2.7.0 (2026-10-11)

v2.7.0 — 首页日期归档、阅读界面焕新与安全加固。

  • 首页日历可与搜索、分类组合；有帖日期可点击，空日期禁用，支持历史月份和清除日期。
  • 原创手记式界面统一首页、文章、编辑器、个人主页与登录入口，改善手机布局、明暗主题、键盘和阅读位置。
  • Markdown 净化库升级并固定到本地，保留表格、代码、视频与任务列表。
  • 内容接口落实登录访问，补强来源校验、封禁权限、同帖回复、上传类型与并发登录锁定。
v2.6.2 (2026-10-11)

v2.6.2 — 图片查看、编辑器与个人主页体验修复。

  • 图片灯箱独立缩放，阻止背景页面跟随放大，关闭后恢复滚动位置。
  • 有序列表按钮接续已有编号，重复点击自动追加下一项。
  • 帖子与评论显示 UTC+8 准确时间，相对时间参考服务器时钟。
  • 个人主页按作者分页，新增按日期查帖日历，灰色日期不可选。
v2.6.1 (2026-07-26)
安全 性能

v2.6.1 — 安全加固与性能优化：会话鉴权重构、CSRF 修复、帖子列表提速。

  • 安全：Cookie 防跨站伪造、会话过期严格校验、评论编辑补齐字数限制、上传移除 SVG、全站新增安全响应头。
  • 性能：帖子列表不再传输全文，缩略图与阅读时长由服务端计算，数据库新增 7 个查询索引。
  • 点赞改为原子事务并自动校准计数；发帖新增标题长度与分类校验。
